# Serdar LifeOS

Персональный offline-хаб в одном HTML-файле: работа, немецкий, права, тело, семья. Ничего не отправляется в сеть, всё хранится локально в браузере.

## Как пользоваться

1. Открой `serdar_lifeos.html` двойным кликом (любой браузер) либо залей в репозиторий и включи GitHub Pages.
2. Вкладка **Cockpit** подстраивает заголовок и фокус под текущий день недели автоматически.
3. Отмечай **чеклист дня** — прогресс и состояние сохраняются по дате (каждый день чистый лист).
4. Кнопка **Reset** очищает чеклист текущего дня; **PDF** — печать/сохранение всей страницы.

## Вкладки

- **Cockpit** — чеклист дня (16 пунктов), прогресс-бар, body-данные, динамический фокус дня.
- **День** — полное расписание 04:30→21:45 с правилом на слот, недельная матрица, добавки/лекарства.
- **Работа** — площадки (локальные + remote), фильтр вакансий A/B/C/D, fit-score, **Job Log с воронкой** (подано → скрининг → интервью → оффер), статус по строке, экспорт CSV/JSON, cover letter, LinkedIn DM, фиксы CV.
- **QA Bank** — ~110 вопросов по 9 категориям, поиск + аккордеон, ответы привязаны к реальным багам Onyx (BE-012, BE-013, JWT) + 5 STAR-историй.
- **Deutsch** — план A2→B1, roadmap до telc, фразы для работы/Arzt/Behörde/Kita.
- **Führerschein** — команды инструктора DE/RU, Abfahrtskontrolle, Grundfahraufgaben, частые провалы.
- **Life Reset** — питание по часам, зал A/B/C, прогрессия, **gym log** (рабочие веса), shopping list, субботний review.
- **Семья** — защищённые точки, лекарство сына, поддержка жены в декрете.
- **Проекты** — ссылки на LifeReset, QA-PRO-Preparation, tki-prep.

## Хранение данных

Чеклисты, Job Log и gym log пишутся в `localStorage` браузера с fallback в память (работает даже там, где localStorage заблокирован, — но тогда данные живут только до закрытия вкладки). Данные привязаны к конкретному браузеру и не синхронизируются между устройствами. Для бэкапа Job Log используй **Export CSV/JSON**.

## Важно

- **Лекарство сына (08:00/19:00):** хаб только напоминает время. Дозу и режим определяет Kinderarzt; при болезни/рвоте/пропуске — звонок врачу, не самодеятельность.
- **CV:** в резюме указан German B1, по факту A2. Синхронизируй на A2 (improving) — несоответствие вскрывается на собеседовании.
- **Зарплатная вилка** в разделе «Работа» — ориентир, проверь по актуальным StepStone/Glassdoor.
- Старые проекты остаются отдельными репозиториями; в разделе «Проекты» — ссылки, обнови их на свои GitHub Pages URL при необходимости.

## Ритм обновления

Раз в неделю, в субботу после взвешивания: занести вес/талию, обновить Job Log, спланировать 3 тренировки и спросить жену, что снять с её плеч на неделю.
